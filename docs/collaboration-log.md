# Collaboration Log

## Session details

- Date: 2026-06-17
- Attendees: Elijah, Bella
- Project: Elevate Horizon Connect
- Purpose: Review the event app direction, confirm the main user flow, and gather feedback for submission improvements.

## Client goals discussed

- Make community events easier to discover and register for.
- Reduce manual admin effort around event enquiries and sign-ups.
- Provide an accessible mobile-first MVP that also works well on tablets.
- Keep the app simple, reliable, and easy to demonstrate for assessment.

## Navigation decisions

- `Home` should give a quick overview and shortcut into the event list.
- `Events` should remain visible without login so guests can browse freely.
- `Event Details` should open from event cards and clearly show key event information.
- `Register` should stay as a separate step from event details so the booking action feels clear.
- `Settings` should remain available from the bottom navigation for theme, text size, and sound options.
- The account page should support `Sign up`, `Sign in`, and a planned Gmail login option without blocking event browsing.

## Risks and concerns raised

- Tablet and wide layouts still need a real visual check to confirm there is no awkward spacing or horizontal scrolling.
- Accessibility still needs a final device-based check for readability, tap targets, and contrast.
- Submission evidence still needs to be collected, especially screenshots, demo evidence, and GitHub commit history proof.
- Real Google or Gmail login is not implemented yet, so the account page must clearly stay marked as a planned future option.

## Feedback and outcomes

- Bella said the app worked great and was easy to use.
- Bella suggested that being able to log in with Gmail in the future would improve the experience.
- The app was updated to include a more professional account screen with sign-up and sign-in states.
- A cleaner Gmail sign-in button was added while keeping guest access to the Events page open.
